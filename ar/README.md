## 🚀 البدء السريع (Quick Start)

### بناء الموقع (Build the site)

```bash
# انتقل لمجلد الترجمة العربية
cd ar

# بناء جميع الفصول
node build.mjs

# أو بناء فصل معين
node build.mjs 00_intro.md
```

### مشاهدة الموقع محلياً

```bash
cd ar/html
# استخدم أي خادم ويب محلي، مثلاً:
python3 -m http.server 8000
# ثم افتح: http://localhost:8000
```

## 📝 أسلوب الترجمة (Translation Style)

### المصطلحات التقنية
المصطلحات التقنية تُترجم للعربي مع الإبقاء على المصطلح الإنجليزي بين قوسين عند **أول استخدام**:

```
المتغير (variable) هو مساحة تخزين مُسمّاة...
```

ثم في بقية النص:
```
يمكن استخدام variable لتخزين البيانات...
```

### التعليقات في الكود
التعليقات داخل الكود تُكتب بالعربية لتسهيل الفهم:

```javascript
// إنشاء متغير (variable) لتخزين المجموع
let total = 0;
```

### الاتجاه (Direction)
- النص العربي: RTL (من اليمين لليسار)
- الكود البرمجي: LTR (يبقى كما هو)
- المصطلحات الإنجليزية: LTR داخل النص العربي

## 🤝 المساهمة (Contributing)

للمساهمة في الترجمة:

1. انسخ (fork) المشروع
2. أنشئ فرعاً جديداً: `git checkout -b translate/chapter-name`
3. اترجم الفصل في `ar/src/`
4. شغّل `node build.mjs` للتحقق
5. أرسل Pull Request

انظر إلى ملف `GLOSSARY.md` للمصطلحات الموحدة.
