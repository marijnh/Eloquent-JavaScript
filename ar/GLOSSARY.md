## قواعد الترجمة

1. **المصطلحات التقنية**: تُترجم بين قوسين عند أول استخدام، ثم تُستخدم بالإنجليزي
   - مثال: "variable (متغير)" ثم "variable" فقط

2. **التعليقات في الكود**: تُكتب بالعربية لتسهيل الفهم
   - مثال: `// حساب المجموع`

3. **مخرجات الكود**: تبقى بالإنجليزي كما هي

4. **أسماء الدوال والمتغيرات**: تبقى بالإنجليزي لضمان عمل الكود

5. **النصوص**: تُترجم بأسلوب عربي طبيعي وسلس

6. **الاقتباسات**: تُترجم للعربية مع الإشارة للمؤلف

## أمثلة على الأسلوب

### النص الأصلي:
"A variable is a named storage for data."

### الترجمة:
"المتغير (variable) هو مساحة تخزين مُسمّاة للبيانات."

### الكود الأصلي:
```javascript
let total = 0;
for (let i = 1; i <= 10; i++) {
  total += i;
}
```

### الكود المترجم:
```javascript
// إنشاء متغير (variable) لتخزين المجموع
let total = 0;

// حلقة تكرار (loop) لجمع الأرقام من 1 إلى 10
for (let i = 1; i <= 10; i++) {
  total += i;  // إضافة الرقم الحالي للمجموع
}

// طباعة النتيجة للكونسول (console.log)
console.log(total);
// → 55
```

## ملاحظات هامة

- يتم الحفاظ على جميع الروابط والمراجع كما هي
- الـ index terms ({{index ...}}) يمكن إهمالها في النسخة المترجمة
- يتم تعديل الـ alt text للصور بالعربية
- يتم الحفاظ على بنية الملف الأصلية (Markdown)
- الكود البرمجي يبقى كما هو، مع إضافة تعليقات عربية
